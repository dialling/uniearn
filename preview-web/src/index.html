How it works: all three phones run the same page code, layouts and styles as the WeChat build, and share one simulated cloud that runs the real order and account logic. Data is kept in this browser until you press Reset. Runner applications are approved instantly. Screenshot reading uses a text reader in your browser (downloaded on the first scan) instead of WeChat's cloud OCR, so it is slower and a little less accurate. Other WeChat-only features (phone-number login, sharing, payments, push notifications) show a message instead.
