# 小程序包体积优化

统计方式：`npm run size` 根据 project.config.json 的 packOptions.ignore 逐文件汇总主包与分包。这里是编译前文件体积，微信开发者工具最终编译、压缩、封装后的数据会有差异。

| 包 | 优化前字节 | 优化后字节 | 优化后 MiB |
| --- | ---: | ---: | ---: |
| 主包 | 3,439,212 | 1,737,494 | 1.66 |
| yuni 视频分包 | 1,094,389 | 1,094,389 | 1.04 |
| 合计 | 4,533,601 | 2,831,883 | 2.70 |

主包减少 1,701,718 字节，约 49.5%。

- 五张等级角色 PNG 从 1,455,821 字节压至 180,387 字节（减少 87.6%）；使用 256 色透明调色板 PNG，保留原始像素尺寸和构图，不转换为 WebP。调色板编码会有细微颜色和半透明像素差异，已对比五张图并检查开发者工具实际等级页效果。
- 原始图片完整备份于 design/asset-originals/yuni-adventure/，manifest.json 记录原图和运行图哈希与尺寸。design 已排除上传；备份不得覆盖回运行素材。
- 经运行代码与动态命名引用核对，五张未引用的 profile-ranks/avatar-*.png 和十五张未引用的 yuni-*.svg 仅排除打包，仍保留文件。实际使用的五张等级徽章、角色 PNG、导航图标继续打包。
- 两版新版签到视频、静音规则、奖励、原生弹窗、页面布局和功能开关保持原样，没有为了缩包回退到旧形象或删掉功能。
- tests/upload-package.test.js 在原有页面、组件完整性检查之外，加入每包 1.8 MiB 的源文件预算及运行素材检查，为编译封装预留空间。新增或替换素材后运行 `npm run size` 与 `npm test`。

验证：完整 npm test（290 个 JS、69 个 JSON 语法检查及全部测试）通过；五张新旧角色图对比，尺寸、透明背景与原图备份哈希检查通过；开发者工具个人页、等级页角色显示正常。未上传发布小程序；GitHub 同步包括优化素材、原图备份、打包规则和体积检查脚本。
