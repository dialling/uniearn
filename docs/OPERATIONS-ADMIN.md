# UniEarn 综合运营后台

后台网站：https://uniearn-news-console.yz768771.chatgpt.site/

## 已连接范围

使用绿色小程序环境 `cloud1-d1g757cev03375e35`。独立后台网站通过 HTTPS 调用 `newsService`；数据库和文件保存在微信云开发，网站源码不包含管理员密码、密钥或用户记录。

- 新闻：双语、封面、草稿、发布、下架、置顶。小程序在 News 页面前台每 5 秒刷新。
- 总览：真实账户、跑手、待审核、订单及待办。页面前台每 30 秒更新。历史归档未建立时，订单数与完成率明确只统计当前订单列表。
- 订单：查询当前及归档订单，标记异常跟进、记录备注，不绕过订单履约流程。
- 用户：分页查询，姓名、手机号默认脱敏；填写原因后可查看完整资料，并记录操作。
- 认证：审核待处理申请，拒绝原因同步到小程序；防止旧申请覆盖和同一学号重复认证。
- 活动：管理优惠活动及跑手奖励规则；orderService 每次同步读取最新配置。已发放优惠券保持领取时的规则。
- 反馈：读取现有客服会话，回复及关闭会话；小程序保留最近会话的最后回复。
- 团队：每人独立账号，相同业务权限；24 小时单次邀请，成员自行设置密码。停用账号会撤销原有登录。初始管理员账号保留用于恢复。
- 操作记录：审核、查看个人信息、异常处理、回复、活动保存、成员管理及新闻修改。

没有接入另一个 pilot 的环境。付款、收入、提现均未接入，不使用模拟数据填充报表。订单金额只是业务标价，不能视作实际收款。云环境里已有的测试订单仍属于该环境的实际存量记录，后台不会替换或清空它们。

## 访问与登录

网站当前维持原有的仅所有者访问限制。应用内邀请创建登录账号，不会自动获得网站托管层的访问资格。需要向实际团队成员单独授予网站访问权限，或在明确批准的部署位置启用统一的应用登录入口。

密码 PBKDF2 SHA256 210000 轮；按用户要求，登录令牌在当前浏览器保存30天，正常使用时自动续期，刷新或重新打开页面会验证并恢复登录。浏览器不保存密码。主动退出、修改密码或停用账号会撤销旧登录。账号连续五次失败锁定15分钟。密码和邀请令牌不写入审计记录。不要公开 `uniearn_news` 集合；保持 ADMINONLY。

## 数据与维护

`uniearn_news`：`admin` 初始账号，`member-*` 成员，`invite-*` 邀请哈希，`content` 新闻，`promotion-config` 活动规则，`audit-*` 操作记录。活动与新闻采用版本检查，发生冲突需刷新后重试。

`uniearn_accounts`：真实账户、跑手申请、学号预留；`uniearn_order_state/team-test`：当前订单和客服会话；`uniearn_order_archive`：历史归档。

部署 `cloudfunctions/newsService`、`orderService`、`studentAccount` 时保持各函数原有环境变量，不复制到网站。新闻函数允许的网页来源在 settings.json 中。后台网站文件在独立 sites/uniearn-news-admin 项目；部署时保持既有项目标识及访问范围。
