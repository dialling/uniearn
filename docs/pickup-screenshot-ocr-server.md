# 取件截图识别：怎么找取件码和驿站（给后端 `/api/ocr/parcel`、`/api/ocr/sms`）

2026-11-27 · 根据用户提供的真实截图（中通物流进度页、菜鸟驿站待取件列表）

## 取件码

1. **取件码字号最大**：截图里取件码（`97-5608`、`8-3-7279`、`26-4-4757`）是整屏最大的字，而且整行只有数字和 `-`。
   腾讯 OCR 的每个 `TextDetections` 都带 `ItemPolygon.Height`：先找**高度明显大于普通文字（约 1.3 倍中位数以上）**、内容基本只有取件码的行，这些就是取件码。
2. 找不到大字时，再找「取件码 / 取货码 / 提货码」后面的号码。
3. **格式校验**：最后一段必须是 3–6 位数字，例如 `8-3-7279`、`26-4-4757`、`97-5608`、`A12-3456`；或者 4–8 位纯数字的柜子码。
   这样能排除地址和日期，例如收件地址「富康苑 2-1」里的 `2-1`。

## 驿站

- 取门店名那一行（含「驿站 / 店 / 兔喜 / 菜鸟 / 妈妈 / 快递站 / 快递柜」），例如「苏州工业园文星东门对面兔喜店」「太仓青草巷广场二十一号店」。
- **不要**取快递 App 自己的文字：「欢迎使用菜鸟驿站」「到驿站的所有包裹都可查」、按钮「联系驿站」、快递员 / 电话 / 地址行。

## 返回给小程序的字段

`{ ok: true, fields: { pickupCodes: [...], pickupPoint: '门店名', candidates: [{ code, point }] } }`

小程序这边（`pages/create` 快递代取「上传截图」）已经会：只保留格式正确的取件码，忽略横幅文字当驿站，把驿站名匹配到列表（兔喜 → 翰林兔喜，妈妈 → 翰林妈妈驿站，菜鸟 → 文缘菜鸟驿站），用户可以再改。
